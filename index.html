FAQ

Can I use joinstr on mainnet right now?

Yes.

Can I use joinstr without Bitcoin Core?

Yes. It can be used as an Electrum plugin which does not require Bitcoin Core. However using untrusted Electrum servers affects your privacy.

Can I use joinstr on mobile?

Yes. An Android app is available from joinstr-kmp.

What fees do I need to pay for using joinstr?

Transaction fees, plus a nostr relay fee if you use a paid relay. There is no coordinator taking a cut. Read more about market making on joinstr to earn fees from pools.

What pool denominations are supported?

Pools are created with custom denominations and a custom number of peers, both configurable by whoever creates the pool.
